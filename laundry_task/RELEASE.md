# Open. Load. Verify.

One new 66-second narrated and captioned MP4, rendered from retained NVIDIA CUDA
physics states. The G1 opens a passive top-loading washer lid, loads a deformable
washcloth, releases it and retracts. The missing opening acknowledgement does not
cause duplicate physical execution; progression uses fresh physical evidence.

Both the delayed and timely-observation reference completed five skills at
23.56 s, then passed three seconds of retention. The full pose traces and event
logs are committed. 32 tests pass; all 1,650 encoded frames decode successfully.
This release is a calibrated feasibility demonstration, not a reliability study
or a comparison against a delay-blind policy.

The robot uses hand-authored IK and ankle feedback. Grasps use idealized compliant
point constraints, and the cloth is a small 16-vertex surrogate. No learned
laundry policy, dexterous finger model, real appliance or hardware is validated.
The first failed retention pilot is retained and explained on the front page.

See the README for exact reproduction commands, model licensing, limitations,
source hashes and the video-to-state index. Historical CPU reaching evidence is
preserved separately and is not relabeled as GPU laundry work.
